Verification Workflow

How ProductGuard Works

End-to-end computer vision pipeline from capture to quantitative similarity assessment.

01
Image Acquisition

User uploads an actual packaging photograph. File integrity and genuine MIME content are validated server-side.

02
Feature Extraction

The image is preprocessed and passed through MobileNetV2 to extract a high-dimensional 1,280-D vector representation.

03
Cosine Distance

Feature vectors are normalized and compared against verified reference embeddings via vectorized cosine similarity.

04
Assessment Report

Displays matched genuine reference, similarity percentage, processing duration, and verification recommendation.
